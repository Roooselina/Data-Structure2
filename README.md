# 데이터 구조 2

데이터 구조 2 과목의 실습 코드 백업입니다(C, 일부 C++). 하나의 Visual Studio 솔루션(`실습.sln`) 아래 장별 프로젝트로 나뉘어 있습니다.

| 프로젝트 | 내용 |
|---|---|
| `정렬1`, `정렬2`, `정렬2_3`, `정렬2_@`, `백준 정렬1` | 정렬 알고리즘 실습과 백준 정렬 문제 |
| `10장_리스트`, `10장_리스트2`, `10장_그래프3`~`5` | 그래프 표현과 탐색 |
| `11장 연습문제 예제` | 11장 연습문제 |
| `13장_탐색`, `13장_해싱` | 탐색, 해싱 |
| `기말_4` | 프로젝트 파일만 있고 소스 파일은 없음 |

`x64/`, `.vs/` 등 빌드 산출물이 함께 커밋되어 있습니다.
